# Backend Fundamentals

Series chia sẻ các kiến thức nền tảng cốt lõi trong kỹ nghệ phần mềm backend: từ giao thức mạng HTTP, kiến trúc RESTful API, định dạng dữ liệu JSON, cơ sở dữ liệu quan hệ SQL (với MariaDB/MySQL), cơ chế giao dịch và tính toàn vẹn dữ liệu (ACID), đến mô hình xử lý bất đồng bộ qua Message Queue và các giải pháp hàng đầu như Apache Kafka và RabbitMQ.

Mục tiêu của series là giúp developer hiểu rõ bản chất vật lý và logic vận hành của các khối kiến trúc backend phổ biến, từ đó tự tin thiết kế hệ thống có độ tin cậy cao, dễ mở rộng và tối ưu hiệu năng.
