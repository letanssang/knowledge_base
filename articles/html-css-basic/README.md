# HTML & CSS Basic

Series nhập môn HTML & CSS dành cho người mới bắt đầu bước chân vào lập trình web hoặc chuẩn bị nền tảng để học các frontend framework hiện đại (như Angular, React, Vue).

Từ việc hiểu cách web và trình duyệt dựng giao diện (DOM tree, Normal Flow), làm chủ cấu trúc trang chuẩn mực với Semantic HTML và Forms, cho đến việc giải mã bản chất của CSS (Box Model, Specificity, Positioning) và thành thạo các kỹ thuật dàn trang hiện đại (Flexbox, CSS Grid, Responsive Web Design).

Mục tiêu của series không phải là học vẹt cú pháp thẻ hay thuộc lòng hàng trăm thuộc tính CSS, mà là giúp bạn hiểu **bản chất cách trình duyệt hoạt động và tư duy layout**: Tại sao thẻ này tồn tại? Tại sao layout bị vỡ? Làm sao để dàn trang chuẩn mực, dễ bảo trì và responsive tốt trên mọi thiết bị? Sau series này, bạn sẽ tự tin dựng giao diện từ thiết kế và có nền tảng vững chắc để tiếp tục với JavaScript và Angular.
