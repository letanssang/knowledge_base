Hội thảo quy tụ các chuyên gia phát triển web hàng đầu để chia sẻ về kiến trúc trình duyệt, chuẩn HTML/CSS và khả năng tiếp cận (Accessibility).

Lịch trình các phiên chia sẻ
Phiên 1: Giải mã thuật toán dựng hình của Browser Engine
Diễn giả: Nguyễn Văn A - Trưởng nhóm Kiến trúc Web

Khám phá cách trình duyệt chuyển đổi chuỗi HTML thành DOM tree, Render tree và cách tránh tái bố cục (reflow).

Phiên 2: Xây dựng giao diện trợ năng chuẩn WCAG
Diễn giả: Trần Thị B - Chuyên gia Khả năng tiếp cận

Khai thác Semantic HTML và ARIA landmark để xây dựng ứng dụng hỗ trợ trọn vẹn cho thiết bị đọc màn hình.
