# Apache Camel

Series tìm hiểu về Apache Camel và Enterprise Integration Patterns (EIP) từ góc nhìn của một backend engineer: từ kiến trúc lõi, cách thiết kế route, xử lý dữ liệu và lỗi, đến kiểm thử, giám sát và triển khai các hệ thống tích hợp phân tán (cloud-native/serverless).

Mục tiêu của series là nắm vững bản chất của việc tích hợp hệ thống, hiểu tại sao một pattern tồn tại, cách giải quyết các bài toán kết nối phức tạp (messaging, streaming, idempotency, resilience) và áp dụng hiệu quả vào dự án thực tế.
