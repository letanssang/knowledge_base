# Mobile Security

Series chia sẻ kiến thức về Mobile Application Security từ góc nhìn của một developer: từ các tiêu chuẩn như OWASP MASVS/MASTG, cách bảo vệ dữ liệu, authentication, network communication đến reverse engineering và các kỹ thuật security testing trên Android/iOS.

Mục tiêu của series là hiểu tại sao một cơ chế bảo mật tồn tại, nó bảo vệ chúng ta khỏi điều gì và cách áp dụng nó vào ứng dụng thực tế, thay vì chỉ làm theo security checklist.
