# Spring Boot

Series trang bị nền tảng kiến thức thực tế về Spring Boot dành cho backend developer: từ cơ chế build dự án với Maven/Gradle, nguyên lý Inversion of Control (IoC) & Dependency Injection (DI), các stereotype annotations (@Component, @Service, @Repository), quản lý cấu hình tập trung với application.properties/YAML, đến xây dựng chuẩn RESTful API (@RestController), xử lý exception và tương tác cơ sở dữ liệu với Spring Data JPA.

Mục tiêu của series là hiểu rõ "ma thuật" đằng sau Spring Boot (Auto-configuration, Spring Container, Component Scanning), giúp developer làm chủ mã nguồn, debug hiệu quả và thiết kế ứng dụng theo đúng chuẩn công nghiệp.
